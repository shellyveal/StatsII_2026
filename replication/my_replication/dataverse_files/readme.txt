README for replication files;
----------------------------
INITIAL DEPOSIT DATE: 12/21/2018
THIS VERSION: 05/13/2019
-----------------------------
ARTICLE: “Descriptive and Substantive Representation in Congress: Evidence from 80,000 Congressional Inquiries”
AUTHORS: Kenneth Lowande, Melinda Ritchie, and Erinn Lauterbach
-----------------------------
Replication code, data, and codebooks needed to reproduce results presented in-text and in the Supplemental Information provided for the study. NOTE: Functions for exporting figures have been excluded. Functions exporting tables will reproduce all results, but note that manual, presentational edits were made to all tables. Please report any errors to Lowande; current contact info: lowande@umich.edu
-----------------------------
FILE LIST:
codebook.pdf -- codebook for all variables included in each data file.
tables-figures.R -- replication code that produces all results presented in the main text and supplementary information.
cluster-se.R -- source code for clustering standard errors
split-del.R -- source code for subsetting dataframe to "split-Senate" delegations
f1-house.Rdata -- data file needed to reproduce Figure 1(a)
f1-senate.Rdata -- data file needed to reproduce Figure 1(b)
f2-reps.Rdata -- member data file needed to reproduce Figure 2
f2-usa.Rdata -- map data file needed to reproduce Figure 2
t1-contacts.Rdata -- data file needed to reproduce Table 1
t2-b10-main.Rdata -- data file needed to reproduce Tables 2 - B10
fc1-districts.Rdata -- optional data file to reproduce simulation results in Figure C1
sim-1.Rdata -- data file to reproduce Figure C1(a)
sim-2.Rdata -- data file to reproduce Figure C1(b)
sim-3.Rdata -- data file to reproduce Figure C1(c)
